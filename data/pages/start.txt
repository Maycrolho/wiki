====== Mi AgendaWeb ======

Bienvenido a la página de mi **AgendaWeb**, una aplicación web para organizar mis actividades, citas y tareas de forma sencilla desde el navegador.

===== ¿Qué es? =====

AgendaWeb es mi proyecto personal para llevar el control de mi tiempo. Permite registrar eventos, consultar lo que tengo pendiente y mantener todo en un solo lugar.

===== Funciones principales =====

  * Agregar, editar y eliminar eventos.
  * Consultar las actividades por fecha.
  * Marcar tareas como completadas.
  * Acceso rápido desde cualquier navegador.

===== Tecnologías utilizadas =====

  * HTML, CSS y JavaScript
  * PHP (servidor local)
  * DokuWiki (documentación del proyecto)
  * MySQL (base de datos)
